# 🌾 NORIFARM – XRISP WebApp

**NORIFARM** is a dynamic Node.js-based crop selection platform built for XRISP. It enables users to interactively explore agricultural products, view crop details in modals, and simulate a digital farming experience with sleek UI/UX.

---

## 📁 Project Structure

XRISP-WEBAPP-DEVELOPMENT/
├── MockData/
│ └── Products.js # Static crop/product data
├── node_modules/ # Node.js dependencies
├── public/
│ ├── app.js # Frontend JavaScript (modal, interactivity)
│ ├── index.html # Main HTML entry point
│ └── styles.css # Custom styles
├── Routes/
│ └── Match.js # Route handling (crop matching logic)
├── server.js # Express server setup
├── package.json # Project metadata and scripts
├── package-lock.json # Dependency lock file
└── README.md # Project documentation


## 🚀 Features

- 🌑 Sleek dark UI with modern animations
- 📦 Modal popup with crop image and description
- ✅ Fixed modal dimensions for better UX
- 🛒 "Buy Now" button with custom styling
- 🧠 Modular code structure (MockData, Routes, Public)

---

## 🛠️ Tech Stack

- Node.js (backend runtime)
- Express.js (server framework)
- HTML5 / CSS3 (frontend UI)
- JavaScript (DOM manipulation & logic)
