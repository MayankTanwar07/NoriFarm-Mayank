# 🌾 NORIFARM – Bring All Farms in Your Hand!

![NORIFARM Banner](https://via.placeholder.com/1000x300?text=NORIFARM+Banner)

**NORIFARM** is an interactive, modern web application that allows users to explore and select crops with real-time UI feedback. Featuring a sleek dark mode interface, animated modals, and crop previews, it provides a powerful frontend for a digital agriculture experience.

---

## 🚀 Features

- 🌙 Dark-themed, responsive UI
- 📦 Stylish modal with image preview and crop details
- 🥦 Preloaded list of common crops (Tomato, Carrot, etc.)
- 🛒 “Buy Now” button with hover effects
- 🎯 Fully modular: Easily extend with backend or API integration
